⚙️ Hard Core Directive Constraints

  • 🚫 Zero Terminal Context Switching: Every internal process, file transaction, and compilation string targets explicit, absolute system coordinates. Relative directory traversal execution steps (cd) are strictly banned.

  • 💥 Visual Demarcation Integrity: Emojis function as structural visual anchors within text streams to assist automated parsing. They must remain embedded directly into execution manifests and never be grouped into an index glossary section.
