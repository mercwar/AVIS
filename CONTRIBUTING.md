# Contributing to AVIS

AVIS defines the comment schema for COM object source code. Contributions
must preserve schema clarity, metadata precision, and AI visibility.

## Development Guidelines

1. **AIFVS-ARTIFACT Headers**  
   Required for all comment objects and schema definitions.

2. **Schema Integrity**  
   No ambiguous fields or non-deterministic metadata patterns.

3. **COM Object Compatibility**  
   All changes must be validated against COM object structure and behavior.

## How to Submit

- Fork the repository  
- Create a feature branch (`git checkout -b feature/AVIS-Schema-Update`)  
- Submit a Pull Request describing the schema refinement  

*Schema Law: Every comment must reveal, never obscure.*
