## AVIS — AI Visibility & Integration Standard

This repository uses the AVIS comment block format to define
machine-readable metadata for all source files. AVIS blocks
appear at the top of each artifact and follow the format
defined in AVIS_SPEC.cmt.

# AVIS: Comment Schema for COM Object Source Code

AVIS defines a structured comment schema for COM object source code,
enabling AI systems to classify, interpret, and reason over embedded
metadata.

## 🧠 Purpose
- Provide a universal comment schema  
- Enable AI‑visible COM metadata  
- Support autonomous reasoning
