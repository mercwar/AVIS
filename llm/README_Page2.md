# AVIS Reference Guide — Page 2

## AVIS Headers
Headers are the backbone of AVIS scanning. They ensure that every file is **self‑describing** and can be parsed consistently by search engines.

---

### Key Elements
- **[Filename comments](ca://s?q=Filename_comments_in_AVIS)** — always present at the top of every file.  
- **[AIFVS mapping](ca://s?q=AIFVS_mapping_in_AVIS)** — defines the artifact type for classification.  
- **[Metadata blocks](ca://s?q=Metadata_blocks_in_AVIS)** — encapsulate contextual meaning and purpose.
